# Crystal Kizor — Personal Brand Website

A modern, responsive personal brand website created as part of the Crystal Kizor Stage 1 assessment. The website presents Crystal's work, professional interests, ideas, speaking opportunities, and broader creative ecosystem through a clean editorial design.

## Overview

The goal of this project is to create a professional online presence that makes it easy for visitors to understand Crystal's work, explore selected projects, learn more about her, and find relevant ways to connect.

## Features

* **Responsive navigation:** Navigation links connect visitors to key sections of the website, with a mobile-friendly menu.
* **Hero section:** Introduces Crystal and provides clear pathways to learn about her and explore her work.
* **Ecosystem section:** Presents the different areas of Crystal's professional and creative work.
* **Selected works:** Highlights projects and directs visitors to a dedicated works page.
* **Works page:** Displays project imagery in a responsive layout.
* **Ideas section:** Provides a dedicated space for Crystal's ideas and perspectives.
* **Speaking section:** Introduces speaking and collaboration opportunities.
* **About section:** Shares information about Crystal.
* **Contact section:** Gives visitors different pathways to make relevant enquiries.
* **Animations and interactions:** Uses motion effects and interactive elements to make the experience feel more engaging.

## Technology Stack

* **Next.js** — React framework for the website.
* **TypeScript** — Type-safe JavaScript development.
* **Tailwind CSS** — Styling and responsive layouts.
* **Framer Motion** — Animations and interactive transitions.
* **React** — Component-based user interface development.

## Getting Started

### Requirements

* Node.js
* npm
* Git

### Installation

Clone the repository and enter the project directory:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_FOLDER
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

### Production Build

To check whether the project builds successfully for production, run:

```bash
npm run build
```

## Design Approach

The website uses a warm, neutral visual palette, editorial-style typography, generous spacing, and project imagery to create a refined professional experience. Responsive layouts and clear calls to action help visitors navigate the site across desktop and mobile devices.
